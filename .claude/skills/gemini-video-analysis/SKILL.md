# 動画の分析スキル（Gemini）

**Claude は動画を見られない・聞けない。** 動画の中身を知りたいときは、このスキルで Gemini に聞く。
Gemini の答えは **「モデルの出力」** であり、数字・秒数・「画面にこう出ていた」は未確認。ユーザーに伝えるときは、そう断る。「全体を見た・聞いた」と言わない。

## 1. 動画を分析する
```bash
python3 .claude/skills/gemini-video-analysis/gemini_video.py "https://www.youtube.com/watch?v=<id>" --out docs/参考動画/<id>_分析.md
python3 .claude/skills/gemini-video-analysis/gemini_video.py <動画ファイル.mp4> --prompt "聞きたいこと"   # 自分で作った動画も見られる
python3 .claude/skills/gemini-video-analysis/gemini_video.py <URL> --start 0 --end 90                    # 一部の区間だけ
python3 .claude/skills/gemini-video-analysis/gemini_video.py --list-models
```
- `--prompt` を省くと、構成・話し方・掛け合い・画面・音・事実を、時刻つきで答える標準の質問が使われる。
- 保存先は `docs/参考動画/`（`--out`）。保存したらコミットして、次のセッションでも読めるようにする。
- 実行場所は、リポジトリのどこからでもよい（上のパスはリポジトリのルートから）。`anime_explainer_apple/` の中では `python3 tools/gemini_video.py …` でも同じ（入口だけ残してある）。

### 聞き方のひな形（目的ごと）
- **参考動画の深掘り**：「映像の質感（絵柄・色・光・ツヤ・湯気）、動き（何がどう動くか・カメラ）、場面切り替えの頻度、『安っぽく見えない』要素と『安っぽく見える』要素、冒頭0〜15秒の見せ方、構成と時間、字幕・テロップ・図解の出し方、BGM・効果音・調理音の入れ方と音量感、キャラや声、再生数が伸びる理由として『言えること／言えないこと』、真似できる点／真似してはいけない固有の要素。数字つきで。分からないことは分からないと」
- **自分の動画の確認**：「声は聞き取りやすいか／BGM の大きさ／効果音は映像の動きと合っているか／絵は安っぽく見えるか、見える所はどこか。聞こえなかったことは、そう書いて」
- **真似してはいけないもの**を必ず聞く（実在人物の口癖・決め台詞・見た目、キャラ、企業ロゴ、映画の映像）。

## 2. 「登録者が少ないのに再生数が多い動画」を探す
```bash
python3 .claude/skills/gemini-video-analysis/yt_search.py "アニメ 料理 解説" "料理 コツ 科学" --max-subs 100000 --top 30 --json out.json
```
- YouTube の検索ページから、再生数・長さ・チャンネル登録者数・「再生数÷登録者数」を集めて、再生数が多い順に出す（API キー不要）。
- 登録者数は「4.07万」などの概数。ページの作りが変わると動かなくなる。ボット確認で止まることもある。
- 見つけた動画は、1. で Gemini に分析させる。**3本ほど選んで、同じ質問で深掘り**すると共通点が見えやすい。

## 3. 動画の静止画を、自分の目で見る（Gemini なしで・無料）
YouTube は途中のコマを公開している。Read ツールで画像を見られる。
```bash
for n in maxresdefault hq1 hq2 hq3; do curl -sS -o ${id}_$n.jpg https://i.ytimg.com/vi/$id/$n.jpg; done
```
`hq1`〜`hq3` は動画の約25%・50%・75%あたりのコマ。Pillow で並べて1枚にして見ると速い。「絵の質感」は Gemini の説明より、これで見たほうが確かなことが多い。

## 4. キーと使える範囲（落とし穴）
- キーは環境の **Network secrets** に登録済みのはず（host `generativelanguage.googleapis.com`、ヘッダー名 `x-goog-api-key`、プレフィックスは空、値は AI Studio のキー）。**ヘッダー名に「Bearer」を付けない。** キーをチャットに貼らせない。無ければ、ユーザーに設定画面から入れてもらう。
- **無料枠は、モデルごとに1日20回ほど。** 並列で何本も動かすと、再試行で回数を使い切る。**1本ずつ順番に**動かす。
- 使えないモデル（上限・混雑・廃止）は、スクリプトが自動で次のモデルに切り替える（`gemini-3.6-flash` → `3.5-flash` → `3-flash-preview` → `3.1-flash-lite`）。全部だめなら、翌日に（上限は1日ごとにリセット）。
- 結果が途中で切れることがある。長い動画は、区間に分ける（`--start/--end`）か、質問を絞る。
- 無料枠で送った内容は、Google が製品改善に使うことがある。**非公開の動画・個人情報は送らない。** 公開されている YouTube の URL は問題ない。
- YouTube の動画ファイル自体は、ボット確認で取れないことが多い。URL をそのまま渡せば Gemini が見る。

## 5. 参考動画の使い方（守ること）
- 参考にするのは「構成・テンポ・画面の作り方・音の入れ方」だけ。**台詞・口癖・見た目・キャラ・映像・ロゴは真似しない。**
- 事実（分量・温度・数字・歴史）は、動画の説明を根拠にしない。公的機関・大学の資料で確認する。
- ユーザーに報告するときは、「確認したこと」（静止画・数値で見た）と「確認できていないこと」（Gemini の出力のまま）を分ける。
