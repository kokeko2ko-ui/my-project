# 感動系YouTube台本 完全制作スキル（kandou-master）

## このスキルの流れ（固定）

```
STEP 1: ヒアリング（必要な場合のみ）
STEP 2: 台本生成（150点設計）
STEP 3: 7人レビュー・初回採点
STEP 4: 修正方針の決定
STEP 5: 修正版台本の生成
STEP 6: 7人再採点
STEP 7: docx + Vrew用テキスト 納品
STEP 8: タイトル/説明文/タグ/サムネイルプロンプト 自動出力
```

プロ編集者スコアが4.5未満、または懐疑的な視聴者スコアが3.5未満の場合は
STEP 4〜6をもう1ループ回す。4.5以上になったら停止。

---

## STEP 1: ヒアリング

以下が会話から読み取れない場合のみ確認する。

1. **ジャンル**：親子の絆 / 逆転劇 / 無名の献身 / 見下され逆転 / 社会的逆転 など
2. **素材の出所**：海外実話ベース / 国内実話ベース
3. **登場人物**：指定あり or 自由設定
4. **核心エピソード**：あれば具体的に
5. **目安尺**：4000文字以上 / 6000文字以上 / 自由

---

## STEP 2: 台本生成（150点設計）

### 全体モチーフの設計（必須）

動画全体を貫く1つのモチーフを設定し、**冒頭・中盤・終盤の3回**登場させる。

| ストーリー例 | モチーフ例 |
|---|---|
| 作家・日記・手紙系 | タイプライターの音、ページをめくる音 |
| スポーツ系 | ホイッスル、シューズの音、歓声 |
| 親子・家族系 | 特定の料理の匂い、口癖、歌 |
| 医療・命系 | 機器の音、窓の外の景色 |

### 5段階構成（必須）

| フェーズ | 役割 | ルール |
|---|---|---|
| ①フック | 最初3〜8秒 | **音・映像描写のみ。説明ゼロ。** |
| ②背景 | 主人公の日常と夢 | 幸福→ギャップの助走。圧縮気味に。 |
| ③試練・選択 | 感情の谷 | 苦労・決断・屈辱を具体的行動で描く |
| ④真実の発覚 | 感情の頂点 | 知られざる事実の開示 |
| ⑤余韻・締め | 視聴者への問いかけ＋CTA | 固定締め文言で締める |

### 感情ピーク4か所（必須）

| ピーク | タイミング | 内容 |
|---|---|---|
| ①第1ピーク | 6〜7分 | 選択・決断・犠牲 |
| ②第2ピーク | 10〜11分 | 知られざる献身の発覚 |
| ③第3ピーク | 14〜15分 | 感情の頂点・核心 |
| ④第4ピーク | 17〜18分 | 視聴者への問いかけ |

### 離脱防止フック4か所（必須）

「でも、本当の話はここからだ」「それは○○日後のことだった」など
**続きへの強制力を持つ一文**で設計する。

### 文章の鉄則

- ✅ 具体的な数字・固有名詞（「1825日間」「午前5時」）
- ✅ 五感の描写（「涙が出るわけでもなく、ただ膝が震えた」）
- ✅ 短文連打で間を作る（「一秒。　二秒。　そして——」）
- ❌ 「感動的な瞬間が訪れました」→出来事を説明しない
- ❌ 「彼は努力し続けました」→具体的な行動で描写する
- ❌ 数字を正確にしすぎない（「32社」より「何十社もの」の方がリアル）
- ❌ 大きすぎる数字（800万部より「40ヶ国語に翻訳」の方が信頼される）

### 固定締め文言（変更不可）

```
このチャンネルでは、忙しい毎日の中で忘れかけている「大切なこと」をお届けしています。
チャンネル登録とベルマークで、次の話もあなたのもとに届けます。
それではまた、心に響くお話でお会いしましょう。
```

## STEP 3: 7人レビュー・初回採点

### 7人の構成（固定）

| # | ペルソナ | 評価の焦点 |
|---|---|---|
| 1 | 30代会社員・男性 | 通勤視聴・1.5倍速保持率・テンポ |
| 2 | 50代主婦 | 感情の温かみ・家族共鳴・シェア欲求 |
| 3 | 20代大学生 | スマホ視聴・スキップポイント・前半保持 |
| 4 | 感動系YouTubeヘビーユーザー | ジャンル適合・オリジナリティ・定番との差 |
| 5 | 感動に懐疑的な視聴者 | 作り話感・ご都合主義・数字の精度・信憑性 |
| 6 | YouTube構成担当 | フック・展開・クライマックス・CTA導線 |
| 7 | 採点役・プロ編集者 | 公開可否・最優先の修正1点 |

### 採点基準（1〜5点、0.25刻み）

| スコア | 判定 |
|---|---|
| 4.5〜5.0 | 強い公開候補 → STEP 7へ |
| 4.0〜4.4 | 軽い修正で公開可 → STEP 4へ |
| 3.5〜3.9 | 構成・信憑性の修正が必要 → STEP 4へ |
| 3.5未満 | 前提・ペーシング・感情軸から再設計 |

**⚠️ 重要：懐疑的な視聴者が3.5以下の場合は、他のスコアが高くても必ずSTEP 4を実行する。**
低評価コメントはアルゴリズムに悪影響を与えるため。

### 出力形式

```
選抜した7人（理由1行）
初回採点（各人：星評価・離脱ポイント・刺さったポイント・改善案）
採点まとめ表（v1スコア一覧）
離脱ポイント TOP3
最優先修正項目
```

## STEP 4: 修正方針の決定

### 修正の優先順位

1. **信憑性ブリッジ**：数字の精度・心理的ブリッジ・行動の自然さ
2. **冒頭フック**：最初3文で謎の問いが生まれているか
3. **感情軸の強度**：一貫したモチーフ・対比・キーフレーズ
4. **中盤テンポ**：繰り返し・背景説明・技術説明の圧縮
5. **クライマックス後の間**：沈黙・余韻の設計
6. **CTA**：ストーリーの教訓に直結しているか

### 信憑性チェックリスト（懐疑的視聴者対策）

- [ ] 数字は「何十社」「数百万人」など丸めた表現か
- [ ] 大きな転換点の前に心理的・時間的ブリッジがあるか
- [ ] 台詞・引用に「〜という」「〜と語った」などの留保があるか
- [ ] 奇跡的な展開に「なぜそうなったか」の1行説明があるか
- [ ] 成功の規模を「質的表現」（翻訳国数・賞・反響エピソード）で補強しているか

---

## STEP 5: 修正版台本の生成

修正方針に従って台本を書き直す。

**保持すべき強い行（絶対に変えない）**
- モチーフの3回登場
- 感情ピークの核心セリフ（「証明できた」「絶対に売れるよ」など）
- 固定締め文言

**修正時の典型パターン**

| 問題 | 修正例 |
|---|---|
| 断り状3連続で失速 | 1つだけ引用し「また。また。また。」に変える |
| 翌日すぐ行動で不自然 | 「一週間後」「数ヶ月後」など時間ブリッジを入れる |
| クライマックス後に急ぎすぎ | 「——しばらく、沈黙が続いた。」1行を入れる |
| 成功数字が大きすぎ | 「40ヶ国語に翻訳」「世界中で読まれた」など質的表現に |
| 背景が長すぎ | 前半を圧縮し、ギャップ提示を早める |

## STEP 6: 7人再採点

同じ7人で再採点し、v1との比較表を出力する。

```
修正方針（箇条書き）
再採点（各人スコア）
v1 vs v2 比較表
最終判定
次に直すなら1点だけ（プロ編集者より）
```

プロ編集者スコアが4.5以上になったらSTEP 7へ進む。
4.5未満なら「次に直すなら1点」を修正してSTEP 5へ戻る。

## STEP 7: docxファイル生成

`/mnt/skills/public/docx/SKILL.md` を参照してdocx-jsで生成する。

**必須記載事項：**
- バージョン・スコア・推定パフォーマンス
- 演出メモ（BGM指示・読み方・間の指示）
- 感情ピーク・フック位置の明示（色分けボックス）
- モチーフ配置の明示

**Vrew用テキスト（.txt）：**
- 演出メモ・記号・パート名をすべて除去
- ナレーション本文のみ
- 空行で自然なポーズを表現

## 文字数チェック（必須）

Vrew用テキストを生成したら必ず文字数を確認する。

```bash
wc -m Vrew用_xxx_ナレーション.txt
```

**判定基準（日本語1文字≒3バイト）**

| wc -m の値 | 日本語文字数の目安 | 判定 |
|---|---|---|
| 12,000以上 | 4,000文字以上 | ✅ 合格 |
| 9,000〜11,999 | 3,000〜3,999文字 | ⚠️ 要拡張 |
| 9,000未満 | 3,000文字未満 | ❌ 大幅拡張必須 |

**合格しなかった場合は以下を拡張する：**

1. **背景パート**：主人公の出身・日常・孤独を具体的なエピソードで膨らませる
2. **試練パート**：感情の低点をもう1〜2シーン追加。五感描写を増やす
3. **核心人物の内面**：動機となった過去の経験を1〜2段落で描く
4. **締めCTA**：「ドアをそっと押さえる」など具体的な行動例を3つ列挙する
5. **モチーフ前後の間**：モチーフが登場する前後に1〜2行の情景描写を追加する

## 実装メモ（このスキルの設計経緯）

このスキルは以下の2スキルの統合版として設計された：

- `kandou-youtube-script`：台本生成・150点スコアリング・docx納品
- `seven-reader-script-review`：7人ペルソナレビュー・修正ループ

**実際の制作で判明した重要な知見：**

1. **懐疑的な視聴者スコアが全体の鍵**：他の6人が4.5以上でも、懐疑的視聴者が3.5以下だと低評価コメントリスクがある。必ず4.0以上にしてから公開する。

2. **数字の精度は信憑性の敵**：「32社に送り14社から返事」のような精確な数字は逆にフィクション感を出す。「何十社もの」の方がリアル。

3. **大きな転換点の前には必ずブリッジ**：「翌日すぐ行動」は不自然。「一週間後」「数ヶ月間動けなかった」など人間的な時間感覚を入れる。

4. **クライマックス後の沈黙は必須**：「インタビュアーは言葉を失った」の後に「——しばらく、沈黙が続いた。」1行入れるだけで余韻が格段に深まる。

5. **断り状の繰り返しは1つ＋短文連打**：断り状を3つ引用するより「そして、また。また。また。」の方が感情的に強く、テンポも落ちない。

6. **wc -m は文字数ではなくバイト数**：日本語1文字は約3バイト。`wc -m` の結果を3で割った値が実際の日本語文字数の目安。12,000以上（＝4,000文字以上）を必ず確認してから納品する。

7. **文字数が足りない場合は背景・試練・核心人物の内面を深掘り**：締め・CTAを増量するより、感情の谷を深くする方が離脱防止にも効果的。
