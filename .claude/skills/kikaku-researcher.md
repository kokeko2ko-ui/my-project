# 企画・リサーチスキル（kikaku-researcher）

## STEP 1: ジャンル確認
以下が不明な場合のみ確認する。
- ジャンル（親子・逆転劇・無名の献身・社会的逆転 など）
- 実話ベース希望か否か
- 制作優先度（急ぎか否か）

## STEP 2: ネタ発掘
以下の切り口でネタを3〜5件リストアップする。

| 切り口 | 内容 |
|---|---|
| 海外実話 | 海外の感動実話・逆転劇 |
| 日本の無名の人物 | メディアに出ていない献身・努力の話 |
| SNSバズ実話 | Xやnoteで話題になった感動エピソード |
| 歴史的人物の裏話 | 教科書に載らない感動エピソード |

## STEP 3: 企画書作成
選んだネタで以下フォーマットの企画書を作成する。

**保存先（必須）：** `kanndou_move/{タイトル}.md`
タイトルが決まっていない場合は仮タイトルで作成し、確定後にファイル名を変更する。

```
# {タイトル}
## ジャンル
## 核心エピソード（3行以内）
## 登場人物
## 想定する感情ピーク
## 参考URL・出典
## 制作優先度（高/中/低）
## ステータス
- [ ] 企画
- [ ] 台本制作中
- [ ] 台本完成
- [ ] メタデータ完成
- [ ] 公開済み
```

## STEP 4: 競合分析（オプション）
「競合も調べて」と言われた場合に実行。
- 同ジャンルの人気動画のタイトル・構成パターンをまとめる
- 差別化ポイントを提案する
