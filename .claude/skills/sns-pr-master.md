# SNS・PRスキル（sns-pr-master）

## STEP 1: 素材確認
以下を確認する（台本の成果物ファイルがあれば自動で読む）。
- 動画タイトル案（仮でOK）
- 核心エピソード・感動ポイント
- ターゲット視聴者

## STEP 2: タイトル生成（5案）

### タイトルのルール
- 32文字以内
- 感情ワード必須：「涙」「感動」「実話」「泣ける」「震えた」など
- 数字があれば必ず入れる
- 末尾に【実話・感動】

```
▼ 推奨案
[タイトル]【実話・感動】

▼ サブ案 ×4
```

## STEP 3: 説明文（概要欄）

フォーマット：
```
[冒頭1文：モチーフ・核心を引く]

[核心エピソードを2〜3行で]

───────────────────
💬 あなたはどう思いましたか？コメントで教えてください。
🔔 チャンネル登録とベルマークで次の話もお届けします。
▶ この動画が良かったらぜひシェアをお願いします。
───────────────────
[固定締め文言]

#感動 #実話 #泣ける [ジャンル別ハッシュタグ5個]
```

## STEP 4: タグ30個

高ボリューム8＋ジャンル8＋チャンネル形式7＋ストーリー固有7

## STEP 5: サムネイルプロンプト（NanoBanana2用）

```
YouTubeサムネイル（16:9）。[背景描写]。
中央の主役：[視覚的要素]。
上部テキスト（白・極太・ゴシック体）：[2行以内]
下部テキスト（赤）：[感情的な結末ワード]
全体の雰囲気：映画ポスター風・感動系・重厚
```

## STEP 6: SNS投稿文

### X（Twitter）用
- 140文字以内
- 動画の核心を1文で
- ハッシュタグ3〜5個

### Instagram用
- 絵文字を適度に使い親しみやすく
- ハッシュタグ10〜15個

## 最後に
全素材をSNS_PR/成果物フォルダに保存する。
