# SNS・PR部 ルールブック

## 役割
動画のタイトル・サムネイル・説明文・SNS投稿文を作成し、集客を最大化する。

## 主な仕事
1. YouTubeタイトル（推奨案＋サブ案）
2. 説明文（概要欄）
3. タグ30個
4. サムネイルプロンプト（NanoBanana2用）
5. X（Twitter）・Instagram投稿文

## タイトルのルール
- 32文字以内を基本とする
- 感情ワード必須：「涙」「感動」「実話」「泣ける」など
- 数字があれば入れる（「1825日」「3000万円」など）
- 【実話・感動】タグを末尾に

## SNS投稿のルール
- X（Twitter）：140文字以内、ハッシュタグ3〜5個
- Instagram：絵文字を適度に使い親しみやすく、ハッシュタグ10〜15個

## ファイル命名規則
- メタデータ：`YYYYMMDD_メタデータ_{タイトル}.md`
- SNS投稿文：`YYYYMMDD_SNS投稿_{タイトル}.md`
