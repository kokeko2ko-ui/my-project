# Gemini による参考動画の分析（結果と使い方）

## 何をしたか
Claude は動画を見られない・聞けないので、**Gemini API に YouTube の URL を渡して**、画面と音声を分析してもらった（`tools/gemini_video.py`）。
結果の全文：`docs/参考動画/RIgguZhy414_分析.md`（笠原さんの「チャーシューエッグ」・約15分）、`docs/参考動画/wpDkbwqFUH8_分析.md`（森田さんの「トンテキ」・約18分）。
**モデルの出力。事実・数値・「画面にこう出ていた」は、確認していない。** 静止画と字幕で確認できた部分（題名の帯が左上、工程名が右上、箇条書きパネル、構成）は、Gemini の説明と一致した。

## 分かったこと（私が以前、静止画と字幕だけから推測していたものとの比較）
| 項目 | 以前の推測 | Gemini の分析 | 判定 |
|---|---|---|---|
| 構成 | 結論→失敗談→コツ→手順 | 冒頭に「完成品のダイジェスト（約20〜27秒）」→悩み→コツ4つ→下準備→調理→実食→おさらい | ほぼ合う。**冒頭のダイジェストが具体的に分かった** |
| 語りの速さ | 約11文字/秒 | 約3.5〜7文字/秒 | **私の誤り**（字幕の二重数え）。字幕の数え直しでも約5〜7文字 |
| 掛け合い | 聞き役がいる | 聞き役が疑問を代弁し、リアクション役（驚き・相づち・称賛）がいる | 合う |
| 画面 | 帯・工程名・パネル・大きな字幕 | 同じ。手元アップと演者を3〜5秒ごとに切り替え。強調語は大きく・色分け | 合う |
| **音** | 不明 | **BGM（軽快なジャズ・アコースティック）、テロップが出るときの効果音（ピコッ、キラリーン）、調理音（ジュージュー・トントン）を大きめに** | **新しく分かった。私たちの動画には、BGMも効果音もない** |
| 脱線・笑い | 脱線がある | 修業時代の昔話、推しの話など | 合う（真似はしない） |

## 私たちの動画との差（次に足せるもの）
1. **BGM と効果音がない。** 「硬い・NHKみたい」の大きな原因かもしれない。足す案：テロップが出る音、反応の文字の音、調理音（ジュージュー）、軽いBGM。作り方の候補は、ElevenLabs の効果音・音楽、または Gemini の音楽モデル（Lyria）。**未試験。**
2. 冒頭の「完成品ダイジェスト」を、約15〜20秒の短いまとめにする（今は食べ物の絵が約5秒）。
3. 試食役（豪快に食べる・驚く）の反応を、もう少し厚くする。
4. 手元のアップ（卵を割る、巻く、焼く）を、絵で見せる回数を増やす。

## 真似しないもの（Gemini も指摘）
実在の店名・人名、決め台詞（「やらんでいい」「イエイ！」）、見た目（髪型・服）、楽屋落ち、危険な昔話（傷口を接着剤で固めた話）。

## Gemini の使い方
```bash
python3 tools/gemini_video.py "https://www.youtube.com/watch?v=<id>" --out docs/参考動画/<id>_分析.md
python3 tools/gemini_video.py <動画ファイル> --prompt "聞きたいこと"      # 自分で撮った動画や、アップロードされた動画も見られる
python3 tools/gemini_video.py <url> --start 0 --end 90                  # 一部の区間だけ
python3 tools/gemini_video.py --list-models                              # 使えるモデル
```
- キー：環境の Network secrets に、ホスト `generativelanguage.googleapis.com`、ヘッダー名 `x-goog-api-key`、プレフィックスは空、値は AI Studio のキー（登録済み）。**ここに「Bearer」を付けない。** キーは、チャットに貼らない。
- モデル（2026-11 時点・無料枠）：`gemini-3.6-flash` が動いた（既定）。`gemini-3.5-flash`、`gemini-3-flash-preview`、`gemini-3.1-flash-lite` も動いた。`gemini-3.8-flash` と `3.7-flash` は混み合って 503 のことがあった。**Pro 系は無料枠で上限超過（429）。** `gemini-2.5-*` は新しい利用者には使えない（404）。モデルは入れ替わるので、`--list-models` と、エラー文の案内を見る。
- 長い動画は、結果を少しずつ受け取る方式（ストリーミング）で動く。混んでいるときは、待って再試行する。
- 料金：課金設定をしなければ無料枠（回数・量の制限あり）。無料枠で送った内容は、Google が製品改善に使うことがある。非公開の動画は送らない。
