# 参考動画の分析（シェフ番組ふうの雰囲気）

ユーザーが「こんな雰囲気で」と示した2本の料理動画（実在の料理人の実写チャンネル）から、雰囲気を取り出したもの。
**表現・台詞・見た目は真似しない。** 取り出したのは、構成・テンポ・画面の作り方だけ。

## 何を根拠にしたか（限界）
- 動画そのものは、私は再生して見る・聞くことができない。YouTube のボット確認で、動画のダウンロードもできなかった。
- 使えたもの：題名・チャンネル名（oEmbed）、サムネイル、YouTube が公開している途中のコマの静止画（各3枚）、自動字幕の全文（各約1万字）。
- そのため「声の抑揚・間・BGM・効果音」は分かっていない。字幕の量（1秒あたりの文字数）と画面の静止画から推測した。

## 分かったこと
**語り（字幕より）**
- 1秒に約5〜7文字（字幕を数え直した値：動画1=約5.3、動画2=約6.6）。※以前「約11文字」と書いたのは、重なって表示される自動字幕を二重に数えた誤り。くだけた口調（「〜やで」「〜ですよ」「ちなみに」）。脱線や思い出話が入る。
- 聞き役との掛け合い。聞き役が「マジっすか」「めちゃくちゃやりたい」と反応し、料理人が答える。
- 「大事なことを4つお伝えします」と、コツを数えてから手順に入る。手順には秒数が入る（「片面30秒」）。
- 冒頭は「全部完璧なレシピです」「食べたい」など、結果や食欲の一言から始まる。

**画面（静止画より）**
- 台所の実景（ステンレスの壁、木のカウンター、吊りフライパン）。
- 上に赤と黄の題名の帯、右上に今の工程名、黄色いパネルにコツが①②③④と溜まっていく。
- 下に大きな縁取り文字の字幕。反応の文字（「ヤバい♡」）。最後に「チャンネル登録・高評価よろしくお願いします！」の黄色い帯。
- サムネイルは、料理が画面いっぱいに大きい。太くて派手な色の文字。

## このプロジェクトでの取り入れ方
| 参考動画 | アニメでの作り方 |
|---|---|
| 台所の実景 | `Kitchen`（`src/Hud.tsx`）の背景 |
| 料理人＋聞き役 | `シェフ`と`後輩`の2人。声も2人（`voices.json`）。話している人だけ口が動く |
| 題名の帯・工程名・コツのパネル | `banner` / `section` / `points`（絵コンテに書く） |
| 大きな縁取りの字幕 | `Telop`。話者ごとに色（シェフ=白、後輩=黄） |
| 反応の文字 | カットの `reaction` |
| 最後の登録帯 | カットの `cta` |
| 料理が大きい | `food` 場面（卵焼き・溶き卵のイラスト） |
| 速い語り | 音声を約1.2倍に速める（`voices.json` の `atempo`） |

## 絵コンテの書き方（`layout: "show"`）
```json
{ "style": "simple", "layout": "show",
  "banner": ["失敗しない!", "ふわふわ卵焼き"],
  "points": ["泡立てない", "弱火のまま", "砂糖ひとさじ"],
  "cast": {"mina": "chef_pro", "taro": "kohai"},
  "speakers": {"シェフ": "mina", "後輩": "taro"},
  "cuts": [ {"s": 0, "type": "food", "section": "オープニング"},
            {"s": 5, "type": "chat", "reaction": {"text": "マジっすか!?", "x": 1250, "y": 300}},
            {"s": 8, "type": "list", "showPoints": 3},
            {"s": 66, "type": "chat", "cta": "チャンネル登録・高評価\nよろしくお願いします!"} ] }
```
- `section`：右上の工程名（次に変えるまで引き継ぐ）。`showPoints`：コツのパネルに出す数（引き継ぐ）。`hl`：いま光らせるコツの番号。
- 台本は `シェフ：…` / `後輩：…` の行で書く（`voices.json` のキーと同じ名前）。読み用の台本も同じ形。

## 気をつけること
- シェフの肩書きを台本・画面で名乗らない（「ミシュラン出身」など事実でないことを言うと誤解を招く）。見た目は、高いコック帽・白い調理服・口ひげのキャラ。
- 実在の料理人・チャンネルの口癖・台詞・見た目を使わない。
