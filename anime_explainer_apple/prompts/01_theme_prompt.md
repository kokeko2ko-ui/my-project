# 01 テーマ決めのプロンプト（ひな形）

> 使い方：`{{...}}` を、`channels/<ジャンル>.md` の値で埋める。
> {{CHANNEL_DESC}}＝チャンネルの説明 / {{COUNT}}＝案の数 / {{TARGET}}＝視聴者 / {{EXCLUDE}}＝除外テーマ（作った・競合が作った）/ {{PRIORITY}}＝優先したいジャンル（任意）/ {{CRITERIA}}＝テーマを選ぶ基準 / {{GENRE_ORDER}}＝伸びやすいジャンルの順 / {{TITLE_PATTERNS}}＝タイトルの型 / {{SAFETY}}＝避けること

---

あなたは、{{CHANNEL_DESC}}の企画責任者です。
下の条件で、再生数が伸びる動画テーマを考えてください。

■出力ルール(最重要)
・出力するのは、番号付きの動画タイトル案のリストだけです。
・前置き、あいさつ、解説、表、補足、出典、期待度などは一切書かないでください。
・1行に1案。形式は「1. タイトル」としてください。
・再生数が伸びそうな順に並べてください。

■入力
・出す案の数:{{COUNT}}
・ターゲット視聴者:{{TARGET}}
・除外テーマ(既に作った/競合が作った):{{EXCLUDE}}
・優先したいジャンル(任意):{{PRIORITY}}

■テーマを選ぶ基準(頭の中で判断し、出力はしない)
次の条件を多く満たすテーマほど良いテーマです。
{{CRITERIA}}

伸びやすいジャンルの順番:
{{GENRE_ORDER}}

■事前の調査
・Web検索が使える場合は、最近のニュース・季節・流行を確認してから選んでください。

■守ること
{{SAFETY}}
・除外テーマと、それに近すぎるテーマは出さないでください。
・タイトルの中に、事実として不確かな数字を入れないでください。

■タイトルの型(いずれかを使う)
{{TITLE_PATTERNS}}
