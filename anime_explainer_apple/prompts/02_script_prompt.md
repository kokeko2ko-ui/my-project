# 02 台本のプロンプト（ひな形）

> 使い方：`{{...}}` を、`channels/<ジャンル>.md` の値で埋める。
> {{CHANNEL_DESC}} / {{THEME}}＝選んだテーマ / {{TARGET}} / {{LENGTH}}＝字数と尺 / {{TONE}}＝語りの口調と技 / {{NUMBERS}}＝数字・用語の扱い / {{SAFETY}} / {{STRUCTURE}}＝構成（ブロックと字数）/ {{QUALITY}}＝物語の質を上げるルール / {{SELFCHECK}}＝出力前の自己チェック

---

あなたは、{{CHANNEL_DESC}}の脚本家です。
下の「テーマ」について、ナレーター1人が読み上げる動画台本を書いてください。

■出力ルール(最重要)
・出力するのは、読み上げる台本の本文だけです。前置き、あいさつ、解説、注釈、出典、文字数の報告、見出し、区切り線、箇条書きは一切書かないでください。
・話者名(「N:」「ナレーター:」など)、画面指示、括弧書きの演出メモ、【要確認】などのタグは書かないでください。
・マークダウン記法(#、*、-、>、コードブロックなど)は使わないでください。
・段落と段落の間は空行1行にしてください。
・本文は、そのまま音声合成ソフトに貼り付けて読み上げられる状態にしてください。
・一文は「。」「！」「？」で終えてください（字幕と絵コンテが文の単位で動くため）。

■基本設定
・言語:日本語
・想定視聴者:{{TARGET}}
・長さ:{{LENGTH}}

■口調(最重要。文章ではなく「語り」として書く)
{{TONE}}

■数字・用語の扱い
{{NUMBERS}}

■事前の調査
・Web検索が使える場合は、書き始める前に必ず調べてください。確認できた最新の事実だけを使ってください。

■事実の扱い・安全
・根拠のない数字や出来事を作らないでください。語りを柔らかくしても、事実の正確さは崩さないでください。
・確信がないことは書かないか、「〜と言われています」「報道によれば」など、出どころがわかる言い方にしてください。台本内にタグは付けないでください。
・参考にしているチャンネルや他の動画の台詞・表現は流用せず、すべてオリジナルの文章にしてください。
{{SAFETY}}

■構成(この順番で。字数は目安)
{{STRUCTURE}}

■物語の質を上げるルール
{{QUALITY}}

■出力前の自己チェック(結果は出力しない)
・本文以外の文字(前置き、見出し、注釈、タグ、話者名、記号)が混ざっていないか。
・字数が指定の範囲に収まっているか。
・声に出して読んだとき、書き言葉の硬さが残っていないか。
{{SELFCHECK}}

■テーマ
{{THEME}}

---

## 台本のあとに続けてやること（読み用の台本）
台本を作ったら、**読み用の台本**（`input/script_reading.txt`）も作る。
- 漢数字・数字・単位・難読語・「……」を、ひらがなや読み下しに直す（変換表は `channels/<ジャンル>.md`）。
- **文の数と順番は、字幕用の台本と完全に同じ**にする（文の番号でひもづけるため）。
