# 03 動画作成のプロンプト（Claude Code 用・ひな形）

> 使い方：`{{...}}` を埋めて、Claude Code にそのまま渡す。
> {{EP}}＝回のフォルダ名（例 episodes/tamagoyaki）/ {{CHANNEL}}＝ジャンルの設定ファイル / {{CAST}}＝配役（役名→キャラ）/ {{SCENE_MIX}}＝使うシーンの型の目安

---

## 依頼
`{{EP}}/input/script.txt`（字幕用の台本）と `{{EP}}/input/script_reading.txt`（読み用の台本）から、
「5歳でもわかる」手描き風カートゥーンの解説動画（mp4）を作ってください。
私はプログラミング初心者です。返答は日本語で、専門用語を使わず短く説明してください。
パソコンに何かをインストールする前は、何を・なぜ入れるのかを一言で説明して、許可をとってください。

## 配役（キャラクターの見た目は `src/characters.ts` の `CAST_LIB` から選ぶ）
{{CAST}}
（実在の人物・企業・他のチャンネルのキャラクターには似せないこと）

## 作るもの
- 1920×1080・30fps の mp4。`{{EP}}/out/` に書き出す。
- 絵はすべてコード（SVG）で描く。画像素材は使わない。
- 台本の内容に合わせて、3〜6秒ごとに絵が切り替わる。字幕は台本の文をそのまま、音声に合わせて出す。
- 次の回からも使い回せる仕組み（台本を入れ替えて「次の回を作って」で作れる）。

## 仕組み（この順番で）
1. **音声とタイミング合わせ（自動）**
   - `EP={{EP}} python3 tools/tts_chunked.py`：読み用の台本を約450字ずつに分けて ElevenLabs（Eleven v4・Yukari）で音声にし、文字ごとの時刻と一緒に保存。
   - `EP={{EP}} node tools/make_timings.js`：文ごとの開始・終了秒を `timings.json` に出す（字幕は字幕用の台本の文）。
   - `EP={{EP}} node tools/make_envelope.js`：音の大きさを出す（口パクを音に合わせるため）。
2. **絵コンテ（あなたが書く）**
   - 台本と `timings.json` を読み、カットごとに「何番目の文から始まるか(`s`)」「シーンの型(`type`)」「中身」を `{{EP}}/storyboard.json` に書く。
   - 書いたら、どんな絵になるかを箇条書きで見せて、OK をもらってから次に進む。
3. **動画（Remotion）**
   - `EP={{EP}} node tools/render.js stills`（各カットの静止画）→ 確認 → `preview` or `final`。

## シーンの型
title／talk／duo／list／compare／coins／bars／news／keyword／grid／imac／outro、
料理向け：ingredients（材料）／step（番号つき手順）／pan（フライパン・火加減・湯気）、
雑学向け：quiz（3択クイズ）。
台本に合わない場面があれば型を追加してよい（`src/Scenes.tsx`）。
使い分けの目安：{{SCENE_MIX}}

## 絵コンテのルール
- 1カット＝3〜6秒（文1〜2つ。長い一文は例外）。1カット目は title、最後は outro。
- 同じ型を3回以上続けない。背景の色も続けて同じにしない。
- 吹き出しや見出しは台本をそのまま写さず、10文字前後に短く言いかえる（字幕に全文が出るため）。
- 絵コンテの先頭に `"style": "simple"` と `"cast": {...}` を書く。

## 絵柄のルール
- シンプル版：黒の太い線・丸い角・平塗り。頭がとても大きく体が小さい。目は小さな黒い縦長の丸。特徴は1つだけ。
- まばたき、口パク（音の大きさに連動）、軽い上下の揺れ。
- 手書き風の文字は Yusei Magic、字幕は Zen Maru Gothic の太字。画面の下に黒い半透明の帯。
- どのカットにもゆっくりしたカメラ移動。吹き出しはポンと出て、文字は左から書かれ、線・矢印・グラフは自分で描かれる。
- 大事な絵と文字は字幕にかからない位置（画面の下から約200pxより上）に置く。

## 確認のしかた（必ずやる）
1. `python3 tools/verify.py {{EP}}`（自動チェック）。FAIL が出たら直す。
2. 各カットから1コマずつ静止画を書き出して、自分の目で全部確認する（文字の隠れ・はみ出し・重なり・内容が台本と合っているか）。直したら、そのカットをもう一度確認する。
3. 確認用の動画（`preview`）を書き出して、音・口の動き・読みを確認し、私に見せる。
4. 開発サーバー（Remotion Studio）は使わない。
5. 依存パッケージは `npm audit` で確認する。

## 進め方
1. 環境（Node.js、ffmpeg、ElevenLabs が使えるか）を確認する。
2. 台本と読み用の台本を確認する（文の数が同じか）。
3. 音声とタイミング合わせ → 絵コンテ（私のOK）→ 静止画確認 → 確認用mp4。
4. 私の感想を聞いて直す。OKが出たら本番mp4を書き出す。
5. 本番を Drive や SendUserFile で渡す。
