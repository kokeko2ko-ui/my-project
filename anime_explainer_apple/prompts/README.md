# プロンプトファイルの使い方

解説アニメ動画は、**3つのプロンプト**で作る。ジャンル（チャンネル）が変わったら、
`channels/<ジャンル>.md` を差し込んで、3つのプロンプトを書き換える。

```
01_theme_prompt.md   テーマ決め（タイトル案のリスト）
02_script_prompt.md  台本（読み上げ本文だけ）
03_video_prompt.md   動画づくりの手順（Claude Code 用）
channels/            ジャンル別の設定（視聴者・テーマ基準・構成・口調・安全・配役・シーン）
  business.md        ビジネス・金融史の解説（講座の元ジャンル）
  cooking.md         料理の作り方・レシピ・料理の雑学
  trivia.md          雑学・クイズ
  _template.md       新しいジャンルを作るときのひな形
```

## 差し込み方
1. 作りたい動画のジャンルを決める（なければ `_template.md` をコピーして `channels/<新ジャンル>.md` を作る）。
2. `01_theme_prompt.md` の `{{...}}` を、そのジャンルの設定ファイルの値で埋めて使う。
3. 選んだテーマを `02_script_prompt.md` の `{{THEME}}` に入れる。構成・口調・安全の欄は設定ファイルのものに置き換える。
4. 台本ができたら、`03_video_prompt.md` の手順で動画にする。
5. 作ったあとは、`tools/verify.py` と、設定ファイルの「確認項目」で確認する。

`{{...}}` の意味は各ファイルの先頭に書いてある。
