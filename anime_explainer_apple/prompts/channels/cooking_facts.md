## 卵焼き（卵と砂糖）

### 確認できた（公的機関・大学の資料）
| 内容 | 根拠 |
|---|---|
| 砂糖は水になじみやすく、食品の水分を抱え込む（保水） | ALIC「砂糖類情報」、農林水産省の特集 |
| 砂糖はたんぱく質の熱凝固を抑え、たんぱく質の食品をやわらかくする。甘い卵焼きは固まるのに時間がかかるが、しっかり加熱してもふんわり軟らかく焼ける | ALIC「砂糖類情報」（alic.go.jp/joho-s/joho07_000609.html） |
| 上白糖はショ糖94〜96%、転化糖1〜3%。転化糖（ぶどう糖＋果糖）は還元糖で、メイラード反応（加熱による褐変）の原因物質。ショ糖には還元性がない。**転化糖を含む上白糖を使うと、加熱調理で料理に褐色がつく** | ALIC「砂糖を賢く使って料理上手」（alic.go.jp/joho-s/joho07_000100.html、2010年。文字コードが Shift_JIS なので、取得時は変換が要る） |
| グラニュー糖はほぼ純粋なショ糖で、転化糖を含まない | 同上 |
| 上白糖はグラニュー糖より焼き色がつきやすい。理由は転化糖（還元糖）。出典に河田昌子『お菓子「こつ」の科学』を明記 | note「砂糖と焼き色」（マシテカアカデミー）。本の原文は未確認 |
| カラメル化は糖だけで起き、ショ糖で約160℃以上（160〜182℃） | 神戸YWCA科学教室資料、Culinary Institute of America の用語集 |
| 卵黄は約65℃で固まり始める（65〜70℃） | 大学紀要、複数の解説記事で一致 |
| 卵白が完全に固まるのは約80℃（75〜80℃） | 同上 |

### 確認できなかった・資料によって違う（台本では言い切らない）
- **卵白が固まり始める温度**：55〜75℃と資料で幅がある（「60℃」と言い切らない）。→ クイズは卵黄（65℃）にした。
- 砂糖を入れると卵の凝固温度が**何度**上がるか、**大さじ1でどのくらい**違うか：数値の資料なし。
- **卵焼きで砂糖が焦げやすさをどれだけ増やすか**：公的資料・研究なし。「焼き色がつきやすい」は上白糖の転化糖（ALIC）で言える。「焦げやすい」は経験則。
- 卵自体のぶどう糖の量：確認できず。
- 個人ブログの記述（出典なし）：「砂糖が多いほどメイラード反応が活発」「グラニュー糖は焦げにくい」「中火が基本」。

### 動画での言い方（確認済み）
- 「砂糖は、水をぎゅっとつかまえる。すると卵が固まりにくくなって、火が通ってもふわふわ」（ALIC）
- 「砂糖が入ると、焼き色がつきやすい。家にある上白糖には、焦げ色のもとになる糖が少し入ってるから」（ALIC）
- 「卵黄は、六十五度くらいから固まり始めると言われている」
- 「砂糖は必須ではない。甘いのが苦手なら減らしてよい」
