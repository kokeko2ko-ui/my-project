## 1. 最初にやること
1. 「おんがく」セッション（ローカル）で続ける。iPhone なら Claude アプリの「Code」→「おんがく」、または claude.ai/code。
2. `suno-song-create` スキルを読む。
3. PC は電源につなぎ、スリープさせない（ふたを閉じるとiPhoneから動かせない）。
   ```bash
   powercfg /change standby-timeout-ac 0
   ```
   ```bash
   powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0
   ```
   ```bash
   powercfg /setactive SCHEME_CURRENT
   ```
   元に戻すとき：1行目の `0` を `30`、2行目の `0` を `1` にして、3行目をもう一度。
4. ログイン・CAPTCHA・WAV のアップロードは、PC の前でくろっこがやる必要がある（iPhone からは不可）。

## 2. スキル `suno-song-create` の内容（要約）
| 内容 | 中身 |
|---|---|
| 歌詞の整え方 | 一人称は「僕」・ひらがな表記、助詞「は」→「わ」、「を」→「お」。短いときはサビを繰り返して約3分にする |
| 標準スタイル | `soft acoustic J-pop ballad, 84 BPM, 4/4, acoustic guitar, soft piano, light strings, low key, calm male low vocal using the user's recorded voice, gentle build, gentle fade out` |
| Suno の手順 | 声は **morimori2** を選ぶ → 歌詞・スタイル・タイトルを入れて Create（2バージョンが同時にできる） |
| そのあと | いいね → WAV ダウンロード → 配信用ファイル → TuneCore |
| AI の申告 | 作詞を Claude が直した場合は「はい」。ジャケットも生成AIにチェック |

使い方：歌詞を貼って「一曲作って」と言えば、この手順で進む。
