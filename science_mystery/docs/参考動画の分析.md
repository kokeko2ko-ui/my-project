# 参考動画の分析（2026-11-22・Gemini で画面と音声を分析）

- 動画：https://youtu.be/eiMBLvE02TM （約20分）「2026年 穴場AI副業：科学×宇宙ミステリー動画の自動生成」
- 分析方法：Gemini（gemini-3.8-flash）に YouTube の URL を渡して要約させた。Claude は動画を直接見ていない。数字や固有名詞は Gemini の読み取りで、未確認。

## 中身
1. **ジャンル**：科学ミステリー／宇宙の未解明の謎／思考実験（都市伝説寄りの雑学×サイエンス）。長尺の横型動画だけ。
2. **ベンチマーク**：『科学の敗北録』（@haibukuroku）。21本で登録1.21万・総再生約263万、3週間で44万再生の回がある（動画内の数字）。
3. **使っているもの**：Codex（指示を受けて調査→台本→音声→映像→書き出しまで自動）、ElevenLabs（落ち着いた低めの声）、自作スキル `science-mystery-video`（動画）と「サムネッシー」（サムネ）。
4. **動画を作る指示**：「science-mystery-video を使い、企画番号01の20秒動画を作ってください。出典を調べ、ナレーションと映像を同期して作成すること。」
5. **企画集**：『科学と宇宙 謎の企画集（20選）』の 01「氷の下の海に生命はいるのか（木星の衛星エウロパ）」でデモ。
6. **伸びる理由（動画の主張）**
   - 「自分が生きている世界の前提が崩れる」巨大な問いを、専門知識なしで投げる（例：この世界はシミュレーション？／人類より前の文明は？）。
   - **サムネ＝感情**（恐怖・禁止・危機感で目を止める）、**タイトル＝具体的な疑問文**（知的好奇心でクリック）と役割を分ける。
   - 維持率：落ち着いた低音で聞き流せる声。結論を1つ出して終わらず、**答えに近づくたびに次の問いが出る**連鎖構成。
7. **サムネの型**：黒い宇宙＋光る被写体。上段=白「氷の下には」、下段=赤の極太明朝「何が眠っている？」。
8. 後半は講座・LINE 登録への誘導と「行動する人は1割未満」という精神論（構築には関係なし）。
