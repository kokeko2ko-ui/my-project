# 台本プロンプト（科学ミステリー）

以下で台本を書く。完成したら `episodes/<名前>/input/script.txt` に保存。

```
あなたは科学ドキュメンタリーのナレーション作家です。テーマ「{タイトル}」で、{長さ:約1分=360字／約10分=3,600字}の台本を書いてください。

【構成：問いの連鎖】
1. 冒頭（最初の3文）：対象を一言で示し、すぐに「信じがたい事実」を1つ出す。最後は「〜かもしれません」で謎を残す。
2. 問い1：「なぜ、〜と言えるのでしょうか。」→ 観測・実験の手がかり（誰が・何で・何を見たか）。
3. 問い2：答えに近づいたところで、もっと大きな問いを出す（「では、〜」）。地球の身近な例で想像させる。
4. 現実に戻す：「けれど今のところ、〜の証拠は、まだありません。」（断定しない）
5. 次の一手：これから何が調べるのか（探査機・望遠鏡・年）。
6. 締め：最初の問いを、少し形を変えて投げ返す（答えは言わない）。
長い回は 2〜5 を「問い3・問い4…」と繰り返す。問いごとに区切りの空行を入れる。

【文体】
- です・ます。1文は40字以内を目安。読点で間を作る（ナレーターが落ち着いて読める）。
- 専門用語は1回だけ、すぐ言い換える。
- 数字は出典どおり。丸めるときは「より多い」「およそ」と書き、元の数字より大きく言わない。
- 推測は必ず「〜かもしれません」「〜と考えられています」「〜という説があります」。
- 「NASAが隠している」「確実に〜」など、根拠のない煽りは書かない。

【一緒に出すもの】
- 出典リスト（NASA・大学・論文など。URL付き）→ `sources.md`
- 文ごとに使えそうな画像の検索語（英語）
- タイトル案3つ（具体的な疑問文）とサムネ文字案3つ（上段=白の短い前置き／下段=赤の感情に刺さる一言）
```

## 読み用の台本
`input/script_reading.txt` は script.txt と**文の数を同じ**にして、数字・英字だけ読みに直す
（例：2024年→にせんにじゅうよねん、NASA→ナサ）。
