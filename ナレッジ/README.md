# ナレッジフォルダ 使い方

## 何を入れる？
思いついたことは何でも入れる。精度を上げるほど、AIチームの提案が自分に合ったものになる。

## フォルダ構成
- `チャンネル情報/`：チャンネルのコンセプト・ターゲット・NGルールなど
- `ネタアイデア/`：気になった話・メモ・視聴者コメントで気づいたこと
- `振り返り/`：動画公開後の反省・うまくいった点・改善点

## 使い方例
```
# 今日の気づきをナレッジに追加してください
視聴者コメントで「もっと短い動画がいい」という声が多かった。
次回は15分以内を意識する。
```

## 運用ルール
- 朝起きたらメモ、ミーティング後にメモ、寝る前に振り返りメモ
- 完璧に書かなくていい。思いついたまま箇条書きでOK
