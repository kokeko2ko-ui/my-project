# 企画・リサーチ部 ルールブック

## 役割
次に作る動画のネタを発掘し、企画書としてまとめる。

## 主な仕事
1. トレンドの感動系ネタを調査（海外実話・国内実話）
2. 競合チャンネルの人気動画を分析
3. 企画案を成果物フォルダに保存

## 企画書のフォーマット（必ずこの形式で）
```
# 企画タイトル案
## ジャンル
## 核心エピソード（3行以内）
## 登場人物
## 想定する感情ピーク
## 参考URL・出典
## 制作優先度（高/中/低）
```

## ファイル命名規則
- 企画書：`YYYYMMDD_企画_{タイトル}.md`
- 競合分析：`YYYYMMDD_競合分析.md`
