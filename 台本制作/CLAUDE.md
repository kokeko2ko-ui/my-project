# 台本制作部 ルールブック

## 役割
感動系YouTube動画の台本をゼロから完成品まで仕上げる。

## 使用スキル
- `/kandou-master`：台本生成→7人レビュー→修正→docx納品の完全フロー

## 作業の流れ
1. 参考資料フォルダのネタ・構成メモを読む
2. kandou-masterスキルで台本を生成
3. 7人レビュー・採点・修正ループ
4. 完成台本・Vrew用テキスト・メタデータを成果物フォルダに保存

## 品質基準
- プロ編集者スコア 4.5以上
- 懐疑的な視聴者スコア 4.0以上
- 両方クリアするまでループを回す

## ファイル命名規則
- 台本：`YYYYMMDD_タイトル_v{番号}.docx`
- Vrew用：`YYYYMMDD_タイトル_vrew.txt`
